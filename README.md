End-to-end data analysis project identifying profit leakage and seasonal trends in retail data using Python (Pandas/Seaborn).

# E-commerce Sales & Profitability Analysis

## 📌 Project Overview
This project analyzes 9,000+ transactions from a retail "Superstore" to identify which products drive profit and where the business is losing money.

## 🛠️ Tools Used
- **Language:** Python 3.x
- **Libraries:** Pandas (Data Wrangling), Matplotlib/Seaborn (Visualization)
- **Environment:** Jupyter Notebook / Google Colab

## 🔍 Key Insights
- **The Profit Sink:** Identified that **Tables** are the least profitable sub-category, resulting in a significant loss due to high shipping costs and excessive discounting (>20%).
- **Seasonality:** Confirmed that **November** is the peak sales month, suggesting a need for increased inventory prep in October.
- **Shipping Efficiency:** Calculated an average shipping lag of ~4 days across all regions.
